# Angelica's Home · R36 全屋设计模型

本项目把业主 R01–R36 / C01–C71 的连续户型决策实现为可交互 3D 模型。设计与实现受 [DESIGN_CONTRACT.md](./DESIGN_CONTRACT.md) 约束，完整变更来源见 [DESIGN_CHANGELOG.md](./DESIGN_CHANGELOG.md)。

## 当前模型

- 厨房与储物：储物间西墙按原图相对下方厨房外墙向左外挑约 0.52 m（方案参考），内部继续采用约 0.28 m 浅层收纳和下部推进式留空；厨房仍为北侧水池、左侧双灶与切配、右侧连续案台，设备段为台下洗碗机与台上微波炉，同侧后段为双开门冰箱；厨房—餐厅为三扇玻璃推拉门。
- 公区：进门旁无窗长墙保留半高鞋柜，柜深收至约 0.38 m、落物面降至约 0.98 m，并留约 0.18 m 常穿鞋位；正对高柜保持左开放右玻璃，顶部收口缝控制为约 0.02 m；客厅四座 L 型沙发、阳台侧贵妃和无茶几理念不变，电视中心参考降至约 1.20 m。
- 卧室：书房右半飘窗 U 弧一体 L 桌、端柜和三层书架不变；次卧保留 L 柜与床位并补齐第二只床头柜；主卧床与双床头柜整体南移约 0.40 m（方案参考），衣柜右返加长到约 1.02 m，梳妆台加长约 0.36 m，墙角柜沿西墙和南墙形成低矮三层 L 型。
- 阳台：客厅—生活阳台左侧为无梁开放口；洗衣机与客厅之间完整保留通高承重墙段，洗衣机、洗衣台贴右墙排列，洗衣机上方设置封闭柜与单层开放置物区，水池正上方恢复外窗。
- 原建筑：三处飘窗均为外凸、约 0.45 m 高的实体窗台，两侧为通高实体墙；书房右半飘窗设置 L 型书桌，左半保持留空；主卧半幅桌采用独立支撑与室内侧连接，坐榻和桌体不得破坏原飘窗结构、防水与保温，低矮三层 L 柜采用室内实墙独立固定；主卧北侧共线墙按单段连续直墙表达，消除旧模型拼缝毛边。
- 风格：默认暖木灰简约，并提供白橡自然、意式静奢、暖灰雅致、奶油中古四套备选。五套方案分别定义木纹、石材、织物、金属、玻璃、超哑柜面与灯光，不改变已确认布局。

所有定制柜、设备、洞口与机电尺寸均为方案参考；施工前必须完成结构核验和完成面复尺。

## 运行

```bash
npm install
npm run dev
```

默认地址为 `http://localhost:3000/`。可用查询参数：

- `?style=minimal|wood|italian|lux|vintage`
- `?mode=orbit|top|walk`

页面支持环绕、顶视、WASD 漫游、房间标签、半透明墙体、二维图对照，以及 R01–R36 决策与风险查看。

## 验证

```bash
npm run check
```

该命令依次执行 ESLint、Vitest 户型不变量测试和生产构建。测试锁定主卧连续直墙、双卧床头柜、主卧睡眠组南移、加长 L 柜和三层转角梳妆柜，同时继续覆盖既有建筑错台、家具、门窗、家政设备和五风格功能包络。

## 权威数据入口

- `src/design/spec.ts`：设计决策、确认状态、风险门禁与优化记录。
- `src/three/plan.ts`：R35 权威墙体、洞口、飘窗、地面、标签与漫游拓扑基线（R36 未改布局）。
- `src/three/furniture.ts`：R35 固定家具、设备与定制柜（R36 未改包络）。
- `src/three/styles.ts`：不改变布局的五套材质和灯光主题。
- `src/design/r18.test.ts`：户型与设计语义不变量测试。
